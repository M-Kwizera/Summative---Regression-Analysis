# Summative — Regression Analysis


## Repository structure

```
summative/
├── pyproject.toml
├── uv.lock
├── linear_regression/
│   └── multivariate.ipynb        # Task 1 — four models, plots, best model saved
├── API/
│   ├── prediction.py             # Task 2 — FastAPI service
│   ├── requirements.txt          # exported with: uv export --format requirements.txt --no-hashes
│   └── best_model.pkl            # generated by running the notebook
└── FlutterApp/
    └── student_gpa_app/          # Task 3 — Flutter mobile app
```

```
cd summative/API
uv run uvicorn prediction:app --reload
# Swagger UI → http://localhost:8000/docs
```
